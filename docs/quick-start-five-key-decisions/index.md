title: "Five Key Decisions"
---

For a reader who needs to orient quickly before diving into the full document:

```text
1. SET YOUR ANNUAL PREMIUM BUDGET
   Pick a band for your investor type and structure.
   Document it in the IPS before placing the first trade.

2. CHOOSE YOUR STRIKE LADDER
   Spread the position across several OTM strikes.
   Weight more toward the middle strike than the tails.

3. SET MATURITY AND ROLL TIMING
   Buy long-dated puts.
   Roll on remaining maturity — before theta accelerates.

4. DEFINE MONETIZATION TRIGGERS IN ADVANCE
   Set triggers on volatility, drawdown and hedge mark-to-market.
   Pre-authorize in the IPS so decisions are not made under stress.

5. DOCUMENT EVERYTHING
   IPS must specify: budget, instruments, strikes, maturities,
   roll rules, monetization triggers, and governance authority.
```

This page is an orientation checklist, not a parameter list. Each decision names what you have to choose; the ranges in common use, and what distinguishes them, live on the page that owns them:

- On decision 1, [Annual Premium Budget Bands](../part-7/typical-hedge-program-targets.md#annual-premium-budget-bands).
- On decision 2, the strike and tenor ladders in [Typical Tail Hedge Structure](../part-7/typical-hedge-program-targets.md#typical-tail-hedge-structure).
- On decision 3, the maturity and roll-interval targets in [Typical Institutional Targets](../part-7/typical-hedge-program-targets.md#typical-institutional-targets). Roll timing is expressed as *remaining* maturity, not elapsed time.
- On decision 4, the trigger set and the rest of the IPS parameter list in [IPS Integration](../part-7/program-constraints-and-governance.md#investment-policy-statement-ips-integration). Monetization at those triggers is staged, never a single transaction — see [Profits Versus Convexity](../part-8/profits-versus-convexity-when-to-take-and-when-to-hold.md#principles-for-deciding).
