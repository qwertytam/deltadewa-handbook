title: "Options Fundamentals"
---

Options terminology is the vocabulary the rest of this handbook is written in. Before tail-hedging structures, Greeks, or program design make sense, a few foundational building blocks need to be in place.

This part covers:

```text
what an option is (calls, puts, strikes, premium)
how an option is priced and carried (spot, forward, rates, dividends, IV)
moneyness (ITM, ATM, OTM, intrinsic vs extrinsic value)
position types (long, short, protective puts, spreads)
exercise and settlement mechanics (American vs European, assignment, cash settlement)
```

None of this is specific to tail hedging — it is the shared language used by every later part. Readers already fluent in options terminology can treat this part as a reference and skip ahead.
