---
title: "Structure 1 — Long OTM Puts (Pure Tail Hedge)"
---

This is the **simplest design**.

Structure:

```text
long deep OTM puts
long maturities
rolled systematically
```

Example:

```text
SPX = 5000
Buy 3500 puts
18 months maturity
```

Advantages:

```text
maximum convexity
maximum crash payoff
strong skew exposure
```

Disadvantages:

```text
high carry cost
theta decay
```

Typical strikes:

```text
20 to 40% OTM
```

Typical maturity:

```text
12 to 24 months
```

#### Characteristics

| Feature      | Value |
| ------------ | ----- |
| Crash payoff | huge  |
| Carry cost   | high  |
| Complexity   | low   |

#### Typical Users

```text
large university endowments
many institutional tail funds
```
