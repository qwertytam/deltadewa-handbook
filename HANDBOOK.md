## If you followed a `HANDBOOK.md#some-anchor` link here

That link is dead, and this file is the wrong place to fix it. This file used
to be the whole handbook, so citations from other repositories anchored into
its headings. The content is now one page per topic under `docs/`, and none of
those old anchors exist here any more.

Repoint the citation at the published site. Links written against the site
survive edits to a page's prose, because they depend only on the file's path
and on the heading text they target.

### How a site URL is built

A page's URL comes from its path under `docs/`, with the `.md` dropped and a
trailing slash added:

```text
docs/part-6/hedge-efficiency-ratio.md
  → https://qwertytam.github.io/deltadewa-handbook/part-6/hedge-efficiency-ratio/
```

The fragment is the slug of the heading you are citing. Slugs are generated by
Python-Markdown's `toc` extension, which this site uses with its default
slugifier, so the rule is:

1. Remove every character that is not a letter, a digit, an underscore, a
   hyphen or whitespace. Punctuation is deleted, not replaced.
2. Lowercase what is left.
3. Collapse each run of whitespace and hyphens into a single hyphen.

```text
## HER Metric                       → #her-metric
## 13. Delta Drift                  → #13-delta-drift
## Rule 1 — Time-Based Roll         → #rule-1-time-based-roll
```

### Two traps worth knowing about

**An em dash does not become a hyphen.** Step 1 deletes it and step 3 collapses
the surrounding spaces, so `Rule 1 — Time-Based Roll` slugs to
`#rule-1-time-based-roll` with **one** hyphen. Writing `#rule-1--time-based-roll`
is the natural guess and it 404s.

**A page's title has no anchor.** Each page's heading is rendered from its
`title:` front matter rather than from a heading in the body, so it never
reaches the table of contents and gets no `id`. Only `##` and deeper headings
in the page body are linkable. To cite a page as a whole, link the page URL
with no fragment.

If you are unsure of a slug, open the page and copy the link from the ¶ symbol
that appears beside each heading — that is the anchor as generated, not as
guessed.
